# Security reporting

Report a suspected TransNote security vulnerability without publishing sensitive details.

Do not publish exploit details, private data, credentials, keys, or a proof of concept in a public GitHub issue.

Repository:

```text
https://github.com/ariDev1/transNote
```

If a private GitHub security-reporting channel is available for the repository, use it.

If no private channel is available, open a normal issue only to request a private reporting channel. Do not include vulnerability details in that public issue.

For non-sensitive bugs and support requests, use:

```text
https://github.com/ariDev1/transNote/issues
```

Marketplace validation, automated tests, and release preflight checks are not a security audit. They do not prove that the software has no vulnerabilities.
